# redion_sms

렌탈마인드 정수기 상담 안내 메시지 작성 앱 (정적 HTML/CSS/JS).

- 공개 주소: https://hrchang517.github.io/redion_sms/ (main 브랜치에 push하면 1~2분 뒤 반영)
- 로컬 미리보기: `python3 dev_server.py` → http://localhost:8769
- 파일을 고친 뒤 `index.html`의 `?v=` 값을 올려야 브라우저 캐시가 갱신돼요.
- Claude 앱 아티팩트용 단일 파일: `python3 tools/bundle_artifact.py . 출력.html`
